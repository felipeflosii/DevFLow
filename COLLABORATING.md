# Colaboração no DevFlow CLI

Para instruções detalhadas de contribuição, consulte **[CONTRIBUTING.md](CONTRIBUTING.md)**, o nome convencional reconhecido pelas ferramentas e pela interface do GitHub.

- Abra issues de bugs com reprodução, logs sanitizados e versão instalada.
- Envie Pull Requests pequenas, com testes e documentação.
- Utilize o modelo de PR em `.github/PULL_REQUEST_TEMPLATE.md`.
- Para problemas de segurança, siga [SECURITY.md](SECURITY.md), sem divulgar dados sensíveis em público.
- Respeite as regras de convivência de [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Mudanças na CLI devem manter retrocompatibilidade de comandos sempre que possível, preservar o modo JSON para automações e evitar operações Git irreversíveis sem consentimento do usuário.
